# SAND DUNE — Playable Build

Play the game: https://raghavgoyalbusiness.github.io/sand-dune-play/

This public repository contains the compiled browser build. The game source is maintained separately in the private [sand-dune repository](https://github.com/raghavgoyalbusiness/sand-dune).

## Controls

- **A / D** or **← / →** steer; **S / ↓** slows; **Shift** sprints.
- **Space** jumps.
- **Left click** or **J** attacks.
- **Q** cycles sand gifts; **F** activates one.
- **Right mouse drag** looks around; **Z / X** rotate the view; **Esc** pauses.
- On touchscreens, use the on-screen controls.
